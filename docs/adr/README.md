# Architecture Decision Records

One file per decision, numbered from `0001`:

```
docs/adr/0001-short-slug.md
```

Each record states the context, the decision, and the consequences — enough that
a future reader understands why the alternative was rejected.

Records are written as decisions actually get made; don't backfill records for
choices nobody debated.
